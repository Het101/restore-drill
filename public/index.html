Restore evidence

Checking the backups

Every few hours the newest backup is pulled from offsite storage, restored into a copy that exists only for the test, proven, and destroyed. A backup counts once it has been restored.

Anatomy of the last drill

  1. 01Find

    The newest backup in the bucket, and fail if it is older than the limit.

    –
  2. 02Restore

    Into a private copy: a temp file for SQLite, a throwaway server for Postgres.

    –
  3. 03Prove

    Integrity, the expected tables, row counts and how fresh the data is.

    –
  4. 04Destroy

    Delete the copy and record the result. Nothing outlives the drill.

    –
